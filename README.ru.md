# Ayla Contract

[English](README.md)

Общее хранилище статусов для расширений в одном процессе Node. Расширения публикуют сигналы, а футер или другой интерфейс читает их. Без runtime-зависимостей, импортов Pi, таймеров и сетевых запросов. Требуется Node 22.18 или новее.

## Установка

Установите библиотеку в Node-проект своего расширения:

```sh
npm install git+https://github.com/kekma-dot/ayla-tools-contract.git
```

Сохраните созданный lockfile, чтобы зафиксировать ревизию. Установка через `pi install` ничего не добавит в интерфейс Pi. Пакет не опубликован в npm.

## Использование

```js
import { publishSignal, readSignals } from "ayla-tools-contract";

publishSignal("voice", { state: "connected", microphone: "ok" });
console.log(readSignals().voice);
publishSignal("voice", undefined);
```

Последний вызов очищает только сигнал `voice`. Каждое расширение должно обновлять и очищать собственный scope.

## API

| Функция | Поведение |
|---|---|
| `signalStore()` | Возвращает общее хранилище, создавая его при первом вызове. |
| `publishSignal(scope, value)` | Записывает один scope. `undefined` очищает его. |
| `readSignals()` | Возвращает неглубокий снимок `quota`, `voice`, `memory`, `transport` и `working`. Пустые scope равны `null`; вложенные объекты остаются общими ссылками. |
| `resetSignals()` | Заменяет всё хранилище. Только для тестов: очищает также сигналы других расширений. |
| `formatCountdown(ms)` | Форматирует миллисекунды как `59m`, `1h30m` или `2d1h`. Для истекших и не конечных значений возвращает `""`. |

Хранилище использует `Symbol.for("ayla.footer.signals.v1")` на `globalThis`. Несколько копий модуля видят одни данные, в том числе после перезагрузки внутри процесса. Перезапуск процесса сбрасывает состояние.

Содержимое сигналов не проверяется. Используйте доверенные константы для scope и не изменяйте объекты, полученные при чтении. Любое расширение процесса имеет доступ к хранилищу; не передавайте через него секреты или приватный контент.

Можно встроить `index.mjs` в другое расширение. Сохраните MIT-лицензию, укажите ревизию и хеш исходника и не меняйте ключ символа.

## Разработка

```sh
npm test
```

Тесты используют встроенный runner Node и не требуют Pi. Для удаления библиотеки уберите зависимость или встроенную копию из использующего её проекта.
